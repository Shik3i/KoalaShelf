# packages/abs-client

TypeScript-Typen und ein schlanker `fetch`-Client für die Audiobookshelf-API. Genutzt von `apps/web` und `apps/desktop`.

Grundlage sind die geprüften Notizen in [docs/api/audiobookshelf.md](../../docs/api/audiobookshelf.md). Die Typen kommen in Phase 1, der Client in Phase 2.
